=====================================
모듈형 Multi-Function 웹앱 - 로컬 실행 사용 방법
=====================================

■ 이 문서를 보는 이유
이 웹앱은 기본적으로 클라우드(Streamlit Community Cloud)에 배포되어 있어
별도 설치 없이 바로 사용할 수 있습니다.

다만 아래 3개 기능은 업로드한 파일이 처리를 위해 클라우드 서버로 전송되므로,
다루는 내부 정보(회사 내부 데이터, 개인정보 등)의 보안이 우려된다면
본인 PC에서 직접 실행해서 사용하시길 권장합니다.

  - 데이터클렌징
  - 대량양식생성기
  - 문서스캔변환기

로컬에서 실행하면 업로드한 파일이 본인 PC 안에서만 처리되고,
외부 서버로 전송되지 않습니다.

■ 준비물
  - Python 3.10 이상 설치 (https://www.python.org/downloads/ 에서 설치,
    설치 시 "Add Python to PATH" 체크)
  - (선택) Git — 없어도 ZIP 다운로드로 진행 가능

■ 소스코드 받기
  이 웹앱의 소스코드(깃허브 주소)는 기획실 지형근 실장에게 문의해주세요.
  전달받은 방법(ZIP 파일 또는 깃허브 주소)으로 소스코드를 받아
  원하는 폴더에 압축을 풉니다.

■ 실행 방법
  1. 압축을 푼 폴더에서 명령 프롬프트(cmd) 또는 PowerShell을 엽니다.
     (폴더 안 주소창에 cmd 입력 후 Enter를 치면 간편합니다)
  2. 아래 명령어를 순서대로 입력합니다.

       pip install -r requirements.txt
       streamlit run app.py

  3. 잠시 후 자동으로 브라우저가 열리고 http://localhost:8501 주소로
     웹앱이 실행됩니다.
  4. 사이드바(또는 홈 화면 카드)에서 원하는 기능을 선택해
     평소처럼 사용하면 됩니다.
  5. 사용을 마치면 명령 프롬프트 창에서 Ctrl + C 를 눌러 종료합니다.

■ 참고 사항
  - 위 3개 기능(데이터클렌징/대량양식생성기/문서스캔변환기)은 API 키가
    필요 없어 별도 설정 없이 바로 사용 가능합니다.
  - 그 외 API 키가 필요한 기능(프롬프트생성기, 공시정보검색, 주가지수및환율,
    아파트실거래가조회)을 로컬에서 쓰려면 별도의 secrets.toml 설정이
    필요합니다. 필요 시 기획실 지형근 실장에게 문의해주세요.
  - 문의사항이나 설치 중 오류가 발생하면 기획실 지형근 실장에게
    문의해주세요.
